The gallery examples were selected because the bundled model can recognize them. They illustrate the interface and cannot be used to estimate model accuracy.

## Interface artwork

`UI/images/jelly-wave.webp` was generated with the built-in image generator using a prompt for a luminous multicolor jelly wave with translucent lime, turquoise, lavender, coral, and orange gel ribbons, grain, and glossy highlights on a dark aubergine background. It was resized and encoded as WebP. The site icon is original artwork.
